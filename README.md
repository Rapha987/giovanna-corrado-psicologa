## Pubblicare il sito

Da [Settings → Pages](https://github.com/Rapha987/giovanna-corrado-psicologa/settings/pages) scegli una delle due:

1. **GitHub Actions** (consigliato) — il workflow `Deploy GitHub Pages` pubblica in automatico a ogni push.
2. **Deploy from a branch** — branch `master`, cartella `/ (root)`.

Dopo un minuto il sito è all'indirizzo sopra.

Il calendario di prenotazione tiene il promemoria sul dispositivo di chi prenota, in linea con l'informativa privacy.
